# Projects

Everything you build on the air or on the bench lives here, one folder per project.

Start from `_template/`. Each project README should answer five things:

1. **What is it** and why is it fun?
2. **License needed** to transmit (or "none, receive only").
3. **Hardware** and rough cost.
4. **How to run or build it.**
5. **Status** and what you learned.

Receive-only projects (RTL-SDR, ADS-B, weather satellites) need no license. Anything that transmits needs the right class and a call sign, and must follow Part 97.
